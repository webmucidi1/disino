# Dişino — Minik Diş Kahramanları

Anaokulu öğrencileri için dokunmatik akıllı tahtaya uygun, Türkçe sesli, web tabanlı diş sağlığı oyunu.

## Oyun kuralları

- Her çocuk 5 yiyecek seçer.
- 5 doğru seçen çocuk animasyonlu Altın Diş Ödülü kazanır.
- En az bir yanlış seçim yapıldığında fırçalama görevi başlar.
- Lekeli diş sayısı yanlış seçim sayısına göre belirlenir (yanlış başına 2 diş).
- Görev tamamlandığında yeniden başlatma seçeneği görünür.

## Çalıştırma

`index.html` dosyasını modern bir web tarayıcısında açın. Harici bağımlılık ve API anahtarı gerekmez.

## GitHub Pages

GitHub deposu oluşturulduktan sonra Settings > Pages altında `Deploy from a branch`, `main` ve `/(root)` seçeneklerini seçin.

Uygulama akıllı tahta için tam ekran modu ve `100dvh` ekran yüksekliğini destekler. Türkçe ses sentezi tarayıcının mevcut seslerine bağlıdır.

> Eğitim notu: Dişlerdeki lekeler ve altın diş ödülü oyunlaştırılmış sembollerdir; tek bir yiyecek tüketimi anında çürük oluşturmaz, fırçalama da mevcut çürüğü iyileştirmez.
